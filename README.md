# راه‌اندازی لندینگ ماکان‌اپ

این راهنما برای راه‌اندازی لندینگ روی Ubuntu با Nginx، فایروال UFW و HTTPS است. دامنه‌های لندینگ `makanapp.org` و `www.makanapp.org` و IP سرور `89.46.217.168` هستند.

## گام ۱: تنظیمات DNS

پیش از اجرای اسکریپت، رکوردهای زیر را در مدیریت DNS دامنهٔ `makanapp.org` تنظیم کنید:

| نوع رکورد | نام | مقدار |
| --- | --- | --- |
| A | `@` | `89.46.217.168` |
| A | `www` | `89.46.217.168` |

صبر کنید تا هر دو دامنه به این IP پاسخ دهند. رکوردهای AAAA ناسازگار را حذف یا اصلاح کنید. هنگام صدور گواهی، در صورت استفاده از پراکسی DNS، آن را روی DNS only قرار دهید. دسترسی ورودی به پورت‌های `80` و `443` باید در فایروال ارائه‌دهندهٔ سرور نیز باز باشد.

## گام ۲: اجرای اسکریپت

برای ایجاد فایل روی سرور، دستور زیر را اجرا کنید:

```bash
cat > setup.sh
```

محتوای کامل اسکریپت ارائه‌شده را بچسبانید؛ پس از خط آخر Enter و سپس `Ctrl+D` را بزنید تا فایل ذخیره شود.

سپس فایل را اجرایی و اجرا کنید:

```bash
chmod +x setup.sh
sudo ./setup.sh
```

اسکریپت بسته‌های سیستم را به‌روزرسانی و ارتقا می‌دهد، ابزارهای لازم را نصب می‌کند، فایروال و Nginx را فعال می‌کند و صفحهٔ آزمایشی `MakanApp - Landing` را می‌سازد. گواهی SSL برای هر دو دامنه با ایمیل `rastinaxoffice@gmail.com` دریافت و انتقال خودکار HTTP به HTTPS فعال می‌شود.

پس از پایان موفق، نشانی‌های زیر را بررسی کنید:

- https://makanapp.org
- https://www.makanapp.org

فایل تنظیمات Nginx در `/etc/nginx/sites-available/makanapp.conf` قرار دارد.

## گام ۳: محل قرارگیری فایل‌های پروژه

محتویات داخل پوشهٔ خروجی استاتیک `dist` یا `build` لندینگ را مستقیماً در مسیر زیر قرار دهید:

```text
/var/www/makanapp/landing
```

خود پوشهٔ `dist` یا `build` را به‌عنوان زیرپوشه کپی نکنید. فایل صفحهٔ اصلی باید دقیقاً در مسیر زیر باشد و جای صفحهٔ آزمایشی را بگیرد:

```text
/var/www/makanapp/landing/index.html
```

پس از بارگذاری، مالکیت و مجوزها را اعمال کنید:

```bash
sudo chown -R www-data:www-data /var/www/makanapp
sudo chmod -R 755 /var/www/makanapp
```
