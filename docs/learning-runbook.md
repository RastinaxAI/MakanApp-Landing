# راهنمای مرکز آموزش و وبلاگ

ابتدا migration تا 0005_learning را با نقش migrator اجرا کنید. Migration داده موجود را حذف یا بازسازی نمی‌کند. همان volume رسانه و نشست‌های مرحله۵/۶ استفاده می‌شوند. مدیر واقعی از فرمان bootstrap مرحله۵ ایجاد می‌شود؛ هیچ حساب پیش‌فرض یا ویدیوی فرضی seed نمی‌شود.

```powershell
docker compose up -d --wait db
docker compose --profile tools run --rm migrate
docker compose up -d --wait api
docker compose exec -T api python -m app.commands.refresh_learning_intro
```

مالک و ویرایشگر در `/admin/learn` به آموزش متنی، ویدیو، مجموعه و وبلاگ دسترسی دارند. فروش به محتوا دسترسی ندارد. دسته/برچسب در `/admin/learn/taxonomy` با بخش آموزش یا وبلاگ ثبت می‌شود. عنوان و ترتیب قابل ویرایش‌اند؛ آدرس و بخش بعد از ثبت ثابت‌اند. مورد ارجاع‌شده در نسخه‌ها حذف نمی‌شود.

۱. تصویر واقعی را در `/admin/media` با alt توصیفی بارگذاری کنید. ویدیو در این uploader پذیرفته نمی‌شود.
۲. نوع محتوا را انتخاب کنید؛ عنوان مدیریتی، slug خوانا، عنوان عمومی، خلاصه، مخاطب، سطح، موضوع و زمان مطالعه را ثبت کنید.
۳. متن با عنوان۲/۳، فهرست، نقل‌قول و تصویر داخلی ویرایش می‌شود. عکس خارجی یا embed HTML پذیرفته نمی‌شود. منابع، مطالب مرتبط و CTA داخلی/HTTPS را ثبت کنید.
۴. برای آپارات، شناسه یا لینک دقیق HTTPS، مدت واقعی و پوستر لازم‌اند. تاریخ بارگذاری و transcript تنها در صورت داشتن منبع واقعی ثبت شوند.
۵. ذخیره نسخه به معنی انتشار نیست. پیش‌نمایش خصوصی را بازبینی کنید، سپس انتشار یا تاریخ انتشار آینده را انتخاب کنید. زمان ورودی محلی به UTC تبدیل می‌شود. پیش‌نمایش noindex و دارای مجوز است.
۶. در مجموعه، مقاله و ویدیو را انتخاب و با بالاتر/پایین‌تر مرتب کنید. اعضای منتشرنشده از خروجی عمومی حذف می‌شوند. تغییر ترتیب بعد از ذخیره تا انتشار اثر عمومی ندارد.
۷. با تاریخچه، نسخه‌های قدیمی پیش‌نمایش و پس از تایید دوباره منتشر می‌شوند. لغو انتشار نمایش عمومی را متوقف می‌کند؛ بایگانی محتوا را برای ویرایش قفل می‌کند.

منتخب خانه فقط برای article/video منتشرشده فعال است و حداکثر سه مورد جدیدتر نمایش می‌یابند. هیچ محتوای منتشرشده‌ای به معنی سکشن خالی یا کارت فرضی نیست. تمام مسیرهای جزئیات، فهرست، دسته و مجموعه SSR هستند. لینک قبلی/بعدی فقط اعضای عمومی همان مجموعه را نشان می‌دهد.

بازدید واجد شرایط در API گزارش می‌شود و به معنی تعداد افراد یا دفعات پخش نیست. حذف کلیدهای منقضی در batch محدود:

```powershell
docker compose exec -T api python -m app.commands.learning_cleanup --batch-size 1000
```

تست‌ها با دیتابیس PostgreSQL جدا اجرا می‌شوند. PowerShell۷ و Node24 لازم‌اند؛ دستور powershell ویندوز۵ قابلیت تولید credential تصادفی launcher را ندارد.

```powershell
docker compose -f compose.test.yaml --env-file .env.test up -d --wait
pwsh -File scripts/test-backend.ps1 -Phase step7
npm run typecheck --workspace=@makan/web
npm run lint --workspace=@makan/web
npm exec --offline --package=node@24 -- node node_modules/next/dist/bin/next build apps/web
pwsh -File scripts/test-web-admin.ps1 -LearnOnly
# بعد از بررسی ماژول، رگرسیون کامل:
pwsh -File scripts/test-web-admin.ps1
# بررسی شبکه مستقل با یک ID واقعی مجاز؛ موفقیت HTTP کافی نیست:
node scripts/check-aparat-live.mjs VIDEO_ID
```

Build سنگین Docker را همزمان با آزمون مرورگر/دیتابیس اجرا نکنید. شواهد مرحله۷ در docs/qa/step7 ذخیره می‌شوند و شواهد قبلی بازنویسی نمی‌شوند. تصویرها و محتواهای fixture پس از توقف launcher حذف می‌شوند؛ volume توسعه و داده واقعی حذف نمی‌شود. نتیجه زنده آپارات باید جدا از تست تزریق قطعی شبکه گزارش شود.
