# بازطراحی کتابخانهٔ طراحی سایت

محدودهٔ این تغییر مسیر `/admin/builder` است. بوم صفحه‌ساز قبلی، محتوای سایت، رسانه‌ها، نسخه‌ها، احراز هویت و CRM حفظ می‌شوند. API یا مدل دادهٔ جدیدی اضافه نشده است.

## تجربهٔ جدید

- کتابخانه، محل اصلی انتخاب و ویرایش طرح‌هاست؛ کارت هر طرح نام واقعی، نوع، وضعیت داشتن نسخهٔ منتشرشده، شمارهٔ نسخه و تاریخ ویرایش را نشان می‌دهد. تاریخچه مستقیماً در دسترس است.
- دسته‌بندی قالب، بخش آماده، سربرگ و پابرگ از فیلتر موجود API استفاده می‌کند؛ صفحه‌بندی همان دسته را نگه می‌دارد. جست‌وجوی نام و وضعیت روی موارد صفحهٔ فعلی انجام می‌شوند و در کتابخانهٔ چندصفحه‌ای این محدوده توضیح داده می‌شود.
- ساخت طرح در پنل جداگانه انجام می‌شود؛ نام و نوع به همان API محتوای موجود ارسال شده و طرح به‌صورت پیش‌نویس در دیتابیس ذخیره می‌شود. پس از ساخت، بوم واقعی باز می‌شود.
- رنگ و فونت و اتصال سربرگ/پابرگ در تب «طراحی سراسری» قرار دارند. تغییر تب، تنظیمات ویرایش‌شده را حفظ می‌کند؛ اعمال روی سایت نیازمند ذخیرهٔ صریح است. کنترل نسخهٔ هم‌زمانی `row_version` حفظ شده است.
- فقط طرح‌های منتشرشده برای اتصال پیشنهاد می‌شوند. برداشتن اتصال، طراحی اصلی سایت را برمی‌گرداند.
- دسترسی تنظیمات برای نقش فاقد مجوز نمایش داده نمی‌شود؛ اعتبارسنجی و مجوزهای سمت سرور تغییر نکرده‌اند.
- منوی معمول مدیریت برای کتابخانه بازگردانده شده است؛ فقط مسیر واقعی ویرایش یک برگه، بوم تمام‌صفحه را فعال می‌کند.
- تصویر بالای کتابخانه یک تصویرسازی تزئینی رابط طراحی است؛ پیش‌نمایش ساختگی از محتوای ذخیره‌شده نمایش داده نمی‌شود.

## فایل‌ها و وابستگی‌ها

- `apps/web/src/features/builder/library-panel.tsx`: رابط تعاملی کتابخانه، پنل ساخت و تنظیمات.
- `apps/web/src/features/builder/library-brand-fields.tsx`: انتخاب رنگ با نام فارسی و کد رنگ، و انتخاب فونت.
- `apps/web/src/app/admin/(protected)/builder/page.tsx`: دریافت فیلتر معتبر و دادهٔ صفحه از API موجود.
- `apps/web/src/features/admin/admin-shell.tsx`: تشخیص دقیق مسیر بوم و بازگشت ناوبری کتابخانه.
- `apps/web/src/styles/builder-library.css` و `globals.css`: جزئیات بصری محدود به کتابخانه.
- `apps/web/tests/v2/library.spec.ts`: پذیرش ساخت واقعی، ذخیره، دسته‌بندی، جست‌وجو، نقش، موبایل، تمرکز صفحه‌کلید و دسترس‌پذیری.
- `advanced.spec.ts` و `theme.spec.ts`: به‌روزرسانی مسیر تعامل با رابط جدید و حفظ آزمون‌های انتشار و رنگ.
- `scripts/run-v2-quality.py`: ثبت شواهد این تغییر در پوشهٔ جداگانه.

کتابخانه از Tailwind، اجزای موجود shadcn و Tabs/Dialog مبتنی بر Radix استفاده می‌کند. وابستگی جدید، Migration یا تغییر قرارداد API ندارد. نتایج اجرا و تصاویر بررسی در `docs/qa/builder-library` ثبت می‌شوند.

## بررسی بصری و اصلاحات

تصاویر دسکتاپ و موبایل کتابخانه و تنظیمات بررسی شدند. کنترل‌های رنگ به کارت‌های خوانا با نام فارسی تبدیل شدند. ایراد بازگشت تمرکز پس از بستن پنل در WebKit رفع شد؛ عنصر بازکننده مستقیماً نگهداری می‌شود تا رفتار به تمرکز خودکار مرورگر وابسته نباشد. حالت کاهش حرکت و کنترل‌های صفحه‌کلید حفظ شده‌اند.

## اجرای بررسی‌ها

```powershell
npm run lint
apps/api/.venv/Scripts/python.exe -X utf8 scripts/run-v2-quality.py build --phase builder-library
apps/api/.venv/Scripts/python.exe -X utf8 scripts/run-v2-quality.py browser --phase builder-library --spec library --project all
apps/api/.venv/Scripts/python.exe -X utf8 scripts/run-v2-quality.py browser --phase builder-library --spec advanced --project all
apps/api/.venv/Scripts/python.exe -X utf8 scripts/run-v2-quality.py browser --phase builder-library --spec theme --project all
```

تست‌های مرورگر از PostgreSQL موقت و API واقعی استفاده می‌کنند و دیتابیس محلی اصلی را تغییر نمی‌دهند. سرویس تست طبق راهنمای موجود باید در دسترس باشد. تصاویر در عرض‌های موبایل و دسکتاپ ذخیره و بررسی شده‌اند؛ عرض‌های ۳۶۰، ۴۸۰، ۷۶۸ و دسکتاپ برای جلوگیری از اسکرول افقی کنترل می‌شوند. گزارش خودکار دسترس‌پذیری نیز بخشی از سناریوهای کتابخانه و تنظیمات است.

APIهای محتوا، کتابخانه، تنظیمات و تاریخچه حفظ شده‌اند؛ Migration جدید وجود ندارد. Commit و Push انجام نشده است.

## نتیجهٔ اجرای نهایی — ۳ آبان ۱۴۰۵

- Build تولید، TypeScript و ESLint موفق بودند؛ بررسی Diff و پیکربندی Compose نیز موفق بود.
- ۱۸ اجرای پذیرش در Chromium، Firefox و WebKit موفق شدند؛ گزارش‌های نهایی بدون شکست، مورد اجرا‌نشده یا Retry هستند. این تعداد شامل ۹ اجرای کتابخانه، ۶ اجرای قالب/انتشار و ۳ اجرای رنگ و فونت است.
- تصویر Docker ساخته و روی `http://127.0.0.1:3100` اجرا شد؛ حضور کد جدید در Bundle سرویس فعال بررسی شد.
- هر چهار سرویس سالم‌اند و هشت بررسی HTTP، شامل حفاظت مسیر کتابخانه، موفق شدند.
- شمارش و Checksum اطلاعات برگه‌ها، نسخه‌ها، رسانه‌ها و درخواست‌ها با قبل برابر است؛ ۲۶ برگه و ۵۰ نسخه حفظ شدند. Migration همان `0009_demo_crm` است.
- جزئیات قابل بررسی در `docs/qa/builder-library/verification.json` ثبت شده است. ارزیابی دسترس‌پذیری این مرحله خودکار است و آزمون دستی با صفحه‌خوان را شامل نمی‌شود.
